# Rishita Chandwani — UI/UX Portfolio

Responsive static portfolio for GitHub + Vercel.

## Run locally
Node 20+ is enough. No npm packages are required.

```bash
npm run dev
```

Open `http://localhost:5173`.

## What's included
- Editorial cream / black / coral visual system
- Responsive laptop, desktop and mobile layouts
- Three equal selected-work cards with full, non-cropped thumbnails
- Clickable case studies for all five projects
- StyleMate video case-study media
- LocalGems customer + seller screen sequence
- Figma / GitHub links for project work
- About section arranged as: headline → journey → what I do + tools
- Tool symbols for Figma, FigJam, Canva, Claude, ChatGPT and Figma Make
- Process: Problem → Business goal → User research → Opportunities → Ideate → Wireframing → Prototype
- No hiring-assignment wording for Augmont; presented as a practice project
- Final contact section with email, phone, Ulhasnagar, Thane · Mumbai and LinkedIn

## Projects
1. StyleMate — AI fashion / wardrobe / virtual try-on, end-to-end
2. It's My Screen — AI ticket booking concept
3. LocalGems — customer + seller local marketplace
4. Augmont — investment flow + dashboard practice project
5. Saiffee Hospital — website redesign study
